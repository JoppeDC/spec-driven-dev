# Agent Instructions

## Project Purpose
This is a Spec-Driven Development PoC. There is intentionally no application code in this repository. All code in `src/` is generated by an AI agent from the specs, schema, and tests. Never treat missing code as something to preserve — it is always disposable and regenerated from scratch.

## Source of Truth (in priority order)
1. `tests/` — if a test says it, the code must do it, exactly
2. `specs/[0-9]_*.md` — feature specs, processed in filename order; each is self-contained
3. `specs/0_Conventions.md` — global API conventions (response format, error shapes, timestamps)
4. `schema/schema.sql` — database structure, column names, types

## Tech Stack
- PHP 8.4, Symfony 8.0
- Doctrine ORM
- PHPUnit for tests
- All endpoints return JSON

## Conventions
- Follow Symfony best practices for service wiring
- Use constructor injection throughout
- One controller per feature spec

## What you must never do
- Modify anything outside of `src/`
- Invent behavior not described in the specs or tests
- Commit any generated code — it is always transient, never persisted to the repository
- Modify spec files, test files, or the SQL schema
